# urbanmart_order_items # UrbanMart Retail Sales - Order Items Dataset

## 📊 Project Overview
This dataset contains transactional details of **order items**. The goal is to analyze sales patterns, product performance, and customer behavior through four stages:
1. Excel Analysis
2. SQL Analysis
3. Python Analysis
4. Dashboard Creation

---

## 🔹 Step 1: Excel Analysis
- Import `order_items.csv` into Excel.
- Use PivotTables to summarize:
  - Total sales by product
  - Monthly order counts
  - Customer purchase frequency
- Apply conditional formatting to highlight top-selling products.
- Create charts (bar, line, pie) for visualization.

**Deliverables:**
- PivotTable reports
- Excel charts
- Summary workbook

---

## 🔹 Step 2: SQL Analysis
- Load dataset into MySQL/PostgreSQL.
- Run queries such as:
  - Top 10 products by sales
  - Monthly revenue trends
  - Repeat customer analysis
  - Seasonal demand patterns

**Deliverables:**
- SQL scripts (`order_items_queries.sql`)
- Exported query results (CSV)

---

## 🔹 Step 3: Python Analysis
- Use Pandas to clean and preprocess data.
- Perform EDA:
  - Sales distribution
  - Product category performance
  - Customer segmentation
- Visualize with Matplotlib/Seaborn.

**Deliverables:**
- Jupyter Notebook (`order_items_analysis.ipynb`)
- Python scripts (`order_items_analysis.py`)
- Visualizations (PNG/HTML)

---

## 🔹 Step 4: Dashboard
- Import cleaned dataset into Power BI/Tableau.
- Build interactive visuals:
  - Total sales overview
  - Product performance
  - Customer purchase trends
  - Time-based analysis
- Add filters for product category and time period.

**Deliverables:**
- Dashboard file (`order_items_dashboard.pbix`)
- Screenshots of dashboard views
